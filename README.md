# Vividia AI Studio — site vitrine

Site statique responsive en HTML, CSS et JavaScript.

## Mise en ligne avec GitHub Pages

1. Décompressez l'archive.
2. Ajoutez `index.html`, `style.css` et `script.js` à la racine du dépôt GitHub `Vividia`.
3. Cliquez sur **Commit changes**.
4. Dans le dépôt, ouvrez **Settings → Pages**.
5. Dans **Build and deployment**, choisissez **Deploy from a branch**.
6. Sélectionnez la branche `main` et le dossier `/ (root)`, puis cliquez sur **Save**.
7. Attendez la publication et ouvrez l'URL affichée par GitHub Pages.

## Important : génération vidéo

Cette version est un site vitrine avec un formulaire fonctionnel qui prépare et copie un brief de production. Elle ne génère pas encore de fichiers vidéo. Pour activer la génération réelle, il faudra connecter un backend sécurisé à un fournisseur vidéo, un service vocal et un moteur de montage.

Ne placez jamais de clés API secrètes dans `script.js` ou dans le code public du dépôt. Les appels API payants doivent passer par un serveur/backend sécurisé.
